# Exercícios Práticos

## Exercício 1 - Entender o Fluxo

Objetivo: identificar cada node do workflow simples.

Tarefa:

- dizer o papel de cada node;
- apontar onde entra e onde sai o dado.

## Exercício 2 - Alterar o Formulário

Objetivo: praticar edição de entrada.

Tarefa:

- adicionar o campo `telefone`;
- remover um campo existente;
- testar o novo payload.

## Exercício 3 - Trocar a API

Objetivo: testar consumo de outra API pública.

Tarefa:

- usar BrasilAPI para outro CNPJ de teste;
- comparar a resposta com a consulta anterior.

## Exercício 4 - Melhorar a Mensagem

Objetivo: usar expressões.

Tarefa:

- montar uma mensagem personalizada com nome e cidade;
- incluir o CNPJ no texto final;
- incluir uma condição simples no texto.

## Exercício 5 - Ajustar O Fluxo Avançado

Objetivo: trabalhar com Gemini.

Tarefa:

- mudar o prompt;
- pedir uma classificação diferente;
- validar se a saída continua útil.

## Exercício 6 - Resolver um Erro

Objetivo: depurar.

Tarefa:

- simular uma URL errada;
- identificar o erro na execução;
- corrigir e reexecutar.
